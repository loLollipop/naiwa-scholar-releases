## 概要

Naiwa Scholar 首次提供公开 Windows x64 安装包，免费开放体验与反馈。同版 Release 提供完整对应源码，开发仓库及提交历史继续独立维护。

## 功能

- **文献与阅读**: 提供本地文库、PDF 阅读、连续阅读与双语阅读功能，支持笔记和批注。
- **Agent**: 支持配置自己的 Agent；Claude Code 与 Codex 的模型选项按各自 Agent 显示。
- **安装资源**: 阅读模型、英文 OCR、PDFium、离线词典和适配器随包提供，无需 Rust 或 Node 开发环境。

## 安装与使用

1. 下载 `Naiwa-Scholar-Windows-x64-Setup.exe`；`SHA256SUMS.txt` 提供 SHA-256 校验值。
2. 运行安装向导，选择可写目录并启动 Naiwa Scholar。
3. 根据首次启动向导选择文库；在线翻译、AI 等功能需要用户自己的服务配置。
4. 升级时选择原安装目录，以沿用 `userdata` 配置；重要文库建议提前备份。

## 源码与许可

- **完整对应源码**: 下载 `Naiwa-Scholar-0.16.2-Source.zip`，其中包含本版应用源码、资源源文件、产品模板、构建脚本、锁文件和本地依赖补丁；按包内 `BUILDING.md` 构建。`SOURCE-FILES.sha256` 提供源文件校验值，Release 的 `SHA256SUMS.txt` 同时校验安装包和源码包。
- **分发许可**: 本版包含 AGPL-3.0-or-later 的 LaTeX 组件，组合应用按该许可分发，原 MIT 和各第三方版权声明继续保留。源码包还提供 `codemirror-lang-latex 0.6.1` 在 npm 对应提交的完整上游源码与 parser 生成脚本；完整许可文本随安装包和源码包提供。

## 已知限制

- **Windows 签名**: 当前安装包未配置 Authenticode 证书，可能显示未知发布者或 SmartScreen 提示。缺少 WebView2 时，安装需要联网。
- **更新与服务**: 当前采用手动下载更新。软件免费提供，第三方 AI/API 服务的费用和配额由相应服务决定。

## Summary

Naiwa Scholar provides its first public Windows x64 installer for free testing and feedback. Complete corresponding source is included in the same Release; the development repository and its history continue to be maintained separately.

## Features

- **Library and reading**: Local libraries, PDF reading, continuous reading, bilingual reading, notes, and annotations.
- **Agents**: Configure your own agents; Claude Code and Codex model options are scoped to the selected agent.
- **Bundled resources**: Reading models, English OCR, PDFium, an offline dictionary, and adapters are included. No Rust or Node development environment is required.

## Installation and usage

1. Download `Naiwa-Scholar-Windows-x64-Setup.exe`; `SHA256SUMS.txt` contains the SHA-256 checksum.
2. Run the installer, choose a writable directory, and launch Naiwa Scholar.
3. Select a library using the onboarding guide. Online translation and AI features require your own service configuration.
4. Choose the existing installation directory when upgrading to retain `userdata` settings. Back up important libraries beforehand.
